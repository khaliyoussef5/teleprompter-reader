# Teleprompter — قارئ السكريبت

تطبيق ويب خفيف لقراءة السكريبتات باللغة العربية أو أي لغة، مع التمرير التلقائي والتحكم في السرعة وحجم الخط.

## المزايا الحالية — V1

- تحرير أو لصق السكريبت وحفظه محلياً داخل المتصفح.
- تمرير تلقائي قابل للتحكم في السرعة أثناء القراءة.
- تعديل حجم الخط.
- إيقاف/استئناف، العودة لأول السكريبت، ومؤشر تقدم.
- عرض معكوس لاستخدام مرآة Teleprompter وخلفية فاتحة اختيارية.
- التطبيق يعمل دون خادم أو قاعدة بيانات.

> **ملاحظة الخصوصية:** النص يبقى داخل متصفحك (localStorage). ما كيتزامنش تلقائياً بين الأجهزة، والمسح ديال بيانات المتصفح قد يمسحو.

## التطوير محلياً

افتح `public/index.html` مباشرة في Chrome. اختياري: `npm test` للتحقق من سلامة الصفحة والسكريبت.

## النشر على Cloudflare Pages باستعمال GitHub

1. أنشئ مستودع GitHub جديد باسم `teleprompter-reader` وخلّي الفرع الرئيسي `main`.
2. ارفع **محتويات** هذا المشروع إلى جذر المستودع مع الحفاظ على مجلد `public`.
3. افتح Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git.
4. اختر `teleprompter-reader`، وفرع النشر `main`.
5. **Framework preset:** None؛ **Build command:** `npm test`؛ **Build output directory:** `public`؛ **Root directory:** `/`.
6. اضغط **Save and Deploy**، ومن بعد خذ الرابط الفعلي الذي يظهر على شكل `*.pages.dev`.

كل تحديث مدموج في `main` سيُطلق نشرًا جديدًا تلقائياً بعد نجاح إعداد الربط.

## طريقة تطوير المشروع

خدّم ميزة واحدة في كل تحديث، اختبرها ثم ادمجها مع `main` باش تبقى النسخة المنشورة مستقرة. المشروع مستقل عن تطبيقات ASSASSAT KHALI الأخرى.
